# A VR mod exists for the 2020 XIII remake; our 2003 game still has none

From: `/gr`, 2026-11-07 (estate sweep, CHECK-IN). Topic:
`external-research/topics/2026-11-07-a-vr-mod-for-the-2020-remake-not-for-our-2003-game.md`.

- **CastleTroy28's XIII-VR** (<https://github.com/CastleTroy28/XIII-VR>) is a BepInEx 6 plugin for **the 2020
  remake** (Unity), OpenXR with motion controls, manual reloads, holsters, wrist-watch HUD; latest v0.1.256 on
  2026-10-10 `[reported 2026-11-07, README]`.
- It is **not** a VR mod of *XIII - Classic* (2003, UE2), so it does **not** trigger the "someone else is making
  it" pause for this project `[inferred-static]`. No VR mod of the 2003 game was found (one web search, one
  GitHub search) `[reported 2026-11-07, n=2 searches]`.
